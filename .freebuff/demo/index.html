🛡️ Sentinel demo scenarios

Open a scenario, then run the Sentinel extension with a prompt from the README. Redactions render live on-page; the popup shows the outbound (sanitized) payload.

  • 🛒 Shop checkout CARD/CVV/PASSWORD/ADDRESS — “Buy this cart”
  • 📧 Webmail inbox PERSON/EMAIL/PHONE/AADHAAR — “Find the OTP code and open it”
  • 👤 Account profile PERSON/PHONE/DATE — “Update my profile”
  • 🔍 Shop search none — “Search for wireless headphones”

Note: All data on these pages is fake. Placeholders like [PERSON_1] shown by the overlay correspond to values that only exist in your local audit ledger.
